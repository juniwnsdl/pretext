## 다섯 차례 점검 결과

동일 코드를 다음 순서로 다섯 번 점검했다.

1. 구조 경계: 조·절·시트·표·단계·부록의 경계
2. 문맥 연속성: 제목·머리행·주의문이 다음 청크에 붙는지
3. 표 처리: 병합·다단 머리행·긴 표·장문 셀
4. 손실·중복: 고유 토큰과 소스 블록의 정확한 1회 소비
5. 경고·사용자 통제: 불확실한 자동 판단의 노출과 안전한 재설정

각 문서 유형 담당 검토자가 공개 원문, 대상 코드, 유형별 회귀 테스트를 독립 대조했다. 전체 테스트·타입 검사·배포 빌드와 실제 화면 검증을 별도로 수행했다.

## 사용자 화면 반영

- 엑셀 설정에 `수식 출력`을 추가했다. 기본값은 `표시값만`, 선택값은 `표시값 + 수식`이다.
- 수식은 재계산하지 않고 Excel 파일에 저장된 표시값을 사용한다고 명시했다.
- 도움말의 **어떤 방법으로 문서를 처리하면 되나요?** 아래에 다음을 추가했다.
  - 병합·다단 머리행은 `상위 > 하위`로 연결하고 인접 중복 제목을 제거
  - 저장된 표시값과 수식 출력 방식, 재계산하지 않는다는 제한
  - Word(DOCX), HWP 변환본, PDF 표는 추출기가 표 구조를 보존한 경우에만 같은 방식으로 처리
  - 셀 메모·댓글은 존재·위치만 감지하고 내용·작성자·답글·멘션·해결 상태는 결과에서 제외
  - 직접 확인된 매뉴얼 숫자 부모와 일반문서의 로마 상위 제목만 보수적으로 청크 문맥에 연결

## 남은 위험과 다음 우선순위

1. **복잡한 PDF 표**: 병합·다단 머리행·회전 글자·도형·페이지 연결 관계가 평탄화되면 정확한 복원을 보장할 수 없다. 원본 대조가 계속 필요하다.
2. **Excel 메모·댓글**: 존재와 위치만 알린다. 본문·작성자·답글·멘션·해결 상태는 의도적으로 결과에 넣지 않으므로 업무상 중요한 정보는 원본 Excel에서 확인해야 한다.
3. **매뉴얼 숫자 계층**: 직접 관찰한 부모가 모두 있는 경우만 최대 4단계로 연결한다. 부모가 빠졌거나 제목 판정이 불확실하면 본문 보존과 검토 경고를 택한다.
4. **일반문서 부모 경로**: 엄격한 로마 상위 제목과 현재 번호 제목만 2단계로 연결한다. 일반 번호 목록이나 보이지 않는 중간 부모까지 넓게 추론하지 않는다.
