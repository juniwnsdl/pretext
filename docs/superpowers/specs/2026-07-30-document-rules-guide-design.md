# 문서 종류별 정리 기준 통합 설계

## 배경

도움말의 `사용 방법` 탭에서 `문서 종류 선택 기준`과 `자동 정리 기준`이 분리되어 있어, 사용자가 어떤 종류를 선택해야 하는지와 선택 후 무엇이 달라지는지를 따로 읽어야 한다. 또한 현재 설명은 엑셀 머리행 감지·수정과 구조화된 계약서 조문 처리 등 최신 동작을 충분히 반영하지 않는다.

## 목표

- 두 섹션을 `문서 종류별 정리 기준` 한 섹션으로 통합한다.
- 모든 종류에 적용되는 공통 규칙과 종류별 선택·정리 기준을 한 흐름에서 설명한다.
- 실제 전처리 코드의 현재 동작을 기준으로 문구를 갱신한다.
- `전처리 설정` 화면의 종류별 설명도 같은 기준으로 맞추되 한 문장으로 유지한다.

## 범위

- `components/usage-guide.tsx`의 도움말 데이터와 섹션 구성을 수정한다.
- `lib/help-guide-layout.ts`의 `사용 방법` 섹션 목록을 하나의 통합 섹션 ID로 정리한다.
- `app/page.tsx`의 네 가지 문서 종류 설명을 간결하게 갱신한다.
- 관련 레이아웃 테스트를 갱신하고, 도움말에서 이전 두 섹션이 다시 분리되지 않는지 검증한다.
- 전처리 알고리즘과 문서 종류 값은 변경하지 않는다.

## 도움말 구성

통합 카드의 제목은 `문서 종류별 정리 기준`으로 한다.

### 공통 정리 기준

카드 상단에서 다음 규칙이 모든 종류에 공통으로 적용됨을 설명한다.

- 페이지 번호는 원문 대조를 위해 보존하고, 페이지 주변에서 반복되는 짧은 머리말·꼬리말은 첫 항목만 남긴다.
- 문서명과 위치·섹션·시트 등 검색에 필요한 문맥을 각 청크에 붙인다.
- MISO의 고정 구분자 `@@@`를 사용하며, 원문에 같은 문자열이 있으면 충돌하지 않게 바꾼다.
- MISO 4,000자 제한에 대비해 청크당 3,800자를 안전 상한으로 사용한다.
- 표와 반복되는 업무 문장은 가능한 한 보존하고, 분할됐다는 이유로 `(계속)` 같은 원문에 없는 문구를 만들지 않는다.

### 종류별 선택 및 정리 기준

각 종류는 한 카드 안에서 `선택 기준`과 `정리 방식`을 함께 설명한다.

1. `법령·사규`
   - 편·장·절·관·조, 부칙·별표·별지처럼 규정 계층이 중심인 문서에 선택한다.
   - 전체 계층과 조문 위치를 문맥으로 붙이고, 긴 조문은 항·호 등 자연스러운 경계를 우선해 나눈다. 표도 해당 위치 문맥과 함께 보존한다.
2. `엑셀·내부 데이터`
   - 행과 열로 구성된 표 데이터나 여러 시트가 있는 통합문서에 선택한다.
   - 시트와 빈 행으로 구분된 표 영역을 섞지 않고 나눈다. Excel에 저장된 반복 머리행을 우선 사용하고, 없으면 자동 감지하며, 사용자가 머리행 범위를 수정할 수 있다. 분할된 표에는 시트명과 머리행을 반복한다.
3. `설명서·업무 매뉴얼`
   - 소제목, 번호 단계, 작업 절차, 주의·경고 문구가 중심인 문서에 선택한다.
   - 섹션과 작업 단계를 기준으로 묶고 주의·안전 문구를 인접한 작업과 함께 유지한다. 표는 해당 섹션 문맥과 함께 별도로 정리한다.
4. `일반 문서·보고서`
   - 보고서, 회의자료, 계약서 등 나머지 일반 문서에 선택한다.
   - 제목·문단·목록·표 경계를 기준으로 나눈다. 구조화된 DOCX 계약서는 반복된 조문 목차를 제거하고, 짧은 조문은 완전한 조문 단위로 묶으며, 긴 조문은 모든 분할 조각에 해당 조문 문맥을 붙인다.

`[위임전결규정 매뉴얼]`과 A~J 항목 구조가 확인되는 특수 문서는 `엑셀·내부 데이터` 외 유형에서 기존 전용 호환 처리가 우선 적용되므로, 도움말 하단에 예외 안내를 짧게 둔다.

## 전처리 설정 화면

선택 카드에서는 상세 동작을 반복하지 않고 핵심 차이만 한 문장으로 보여준다. 좁은 화면에서는 한 열, `sm` 이상에서는 두 열로 배치해 짧은 설명이 지나치게 세로로 늘어나지 않게 한다.

- 법령·사규: `편·장·절·관·조와 부칙·별표·별지의 위치 문맥을 유지합니다`
- 엑셀·내부 데이터: `시트와 머리행을 감지해 표 영역별로 나누며 머리행을 직접 수정할 수 있습니다`
- 설명서·업무 매뉴얼: `소제목·작업 단계와 주의·안전 문구가 떨어지지 않게 나눕니다`
- 일반 문서·보고서: `제목·문단·목록·표를 기준으로 나누고 구조화된 계약서 조문도 인식합니다`

## 검증

- 도움말 레이아웃 테스트에서 `document-types`와 `automatic-rules` 대신 통합 섹션 하나가 배치되는지 확인한다.
- 소스 기반 도움말 테스트로 통합 제목, 네 종류, 최신 핵심 표현이 존재하고 이전 두 제목이 제거됐는지 확인한다.
- TypeScript 검사와 관련 Node 테스트를 실행한다.
- 가능하면 로컬 화면에서 `사용 방법` 탭과 `전처리 설정` 카드의 모바일·데스크톱 배치를 확인한다.
