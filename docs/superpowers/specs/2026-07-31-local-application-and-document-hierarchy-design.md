# 로컬 적용 및 문서 계층 보강 설계

## 목표

공개 문서에서 반복 확인된 구조만 보수적으로 보강하고, 복원 근거가 부족한 내용은 추측하지 않는다. 변경 완료 후 기존 사용자 파일을 보존하면서 `codex/public-document-preprocessing`의 검증된 변경을 로컬 `master`에 반영한다.

## Excel 셀 메모·댓글

- SheetJS가 읽은 실제 셀 객체의 `c` 배열만 검사한다. `주석`이라는 열 이름이나 셀 값은 감지 근거로 사용하지 않는다.
- 구형 메모·노트와 스레드 댓글은 존재와 셀 위치만 감지한다.
- 작성자, 본문, 답글, 멘션, 해결 상태는 추출 문서나 청크에 저장·출력하지 않는다.
- 워크북당 `EXCEL_CELL_COMMENTS_UNSUPPORTED` 경고 하나를 생성한다. `count`는 댓글 메시지 수가 아니라 댓글이 있는 셀 수이며 위치는 문서 순서상 처음 20개만 표시한다.
- 값 없는 먼 셀의 댓글 때문에 `!ref` 전체 사각 범위를 순회하지 않도록 실제 내용·수식·필요한 병합 범위에서 표시 범위를 계산한다. 댓글만 있는 셀은 표시 범위를 확장하지 않는다.
- 댓글만 존재하는 워크북은 지원하지 않는 댓글만 있다는 전용 오류로 원본 확인을 안내한다.

## PDF와 변환 문서의 표

- 단순한 사각형 행·열 표와 추출 단계에서 구조화된 표는 기존처럼 머리행을 반복하고 행 단위로 분할한다.
- 병합 셀, 다단 머리행, 회전 글자, 표 안의 표, 페이지를 넘는 복합 표가 평문으로 추출된 경우에는 열 관계를 자동 복원하지 않는다.
- 결과를 임의로 재구성하지 않고 도움말에서 미지원 범위와 원본 대조 필요성을 명시한다.
- Word, HWP 변환 문서, PDF에서도 추출 결과에 표 구조가 남아 있을 때만 Excel과 유사한 표 처리 품질을 기대할 수 있다고 안내한다.

## 매뉴얼 깊은 번호

- 짧고 문장형·명령형이 아닌 숫자 제목 `1`, `1.1`, `1.1.1`을 최대 4단계까지 식별한다.
- 직접 부모 번호가 앞에서 실제 제목으로 확인된 경우에만 `1 제목 > 1.1 제목 > 1.1.1 제목` 경로를 구성한다.
- 부모 또는 중간 번호가 누락되면 계층을 추측하지 않는다. 원문을 한 번 보존하고 `manual-deep-numbering-unstructured` 검토 경고를 유지한다.
- 기존의 연속 `1./2./3.` 체크리스트, 작업 단계, 안전문구 결합 규칙은 바꾸지 않는다.
- DOCX처럼 명시적 `headingPath`가 있으면 추론 번호보다 우선한다.

## 일반문서 부모 경로

- 기존의 엄격한 ASCII/Unicode 로마 제목 판정에 성공한 `I~XII`, `Ⅰ~Ⅻ + 한글 제목`만 상위 부모로 기억한다.
- 연속 목록으로 판정되지 않은 숫자 제목만 `[로마 상위 제목, 현재 숫자 제목]`의 2단 경로를 사용한다.
- `1.1`에서 보이지 않는 `1.` 부모를 추가로 추론하지 않는다.
- 새 로마 제목은 부모를 교체한다. Markdown 제목, 법률 조문, 장·절, 영문 구조 제목, 명시적 `headingPath`, 별도 서식 제목이 나오면 추론 부모를 해제한다.
- `C 70%`, `D 55%`, `PPT`, `A4`, `가./나.`는 기존처럼 본문으로 남긴다.
- 본문 없는 로마 부모의 출처 ID는 첫 자식 청크에 한 번만 연결하고 부모 제목을 본문에 중복 삽입하지 않는다.

## 도움말 보강

`어떤 방법으로 문서를 처리하면 되나요?` 영역에 다음을 간략히 추가한다.

- Excel 수식은 저장된 표시값을 사용하며 재계산하지 않는다는 점
- Excel 셀 메모·댓글은 존재만 감지하고 내용은 결과에 포함하지 않는다는 점
- 병합·다단 머리행은 `상위 > 하위`로 연결하지만 복잡하면 원본 확인이 필요하다는 점
- Word, HWP 변환 문서, PDF 표도 구조가 보존된 경우에만 같은 방식으로 처리된다는 점
- 복잡한 PDF 표는 정확한 셀 관계 복원을 보장하지 않는다는 점
- 매뉴얼의 확인된 숫자 부모 경로와 일반문서의 로마 상위 경로를 청크 문맥에 반복한다는 점

## 오류 처리와 성능

- 주석 감지는 실제 생성된 셀 키만 순회한다.
- 경고 위치 목록은 20개로 제한하지만 총 셀 수는 정확히 유지한다.
- 주석 본문이나 작성자 정보가 결과·경고에 노출되지 않도록 한다.
- 모든 경로 보강은 3,800자 안전 한도, 원본 블록 1회 소비, 표 머리행 반복 규칙을 그대로 지킨다.

## 검증

- 테스트를 먼저 실패시킨 뒤 최소 구현으로 통과시킨다.
- Excel: 레거시 메모, 스레드 댓글, 빈 댓글 셀, 21개 이상 위치 제한, 먼 희소 댓글 셀, 댓글 본문 미출력.
- 매뉴얼: `1 > 1.1 > 1.1.1`, 부모 누락, 연속 체크리스트, 안전문구, raw block 경계.
- 일반문서: ASCII/Unicode 로마 부모, `1.`과 `1.1`, 새 로마 부모 교체, C/D 등급, PPT/A4, 구조화 경로 우선.
- 도움말 문구 렌더링, 전체 자동 테스트, TypeScript, 프로덕션 빌드, 브라우저 화면을 검증한다.
- 검증 후 로컬 `master`에 병합하고 원본 폴더에서 전체 테스트를 다시 실행한다.
